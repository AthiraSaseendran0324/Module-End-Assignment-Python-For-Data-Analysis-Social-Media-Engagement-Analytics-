# Module-End-Assignment-Python-For-Data-Analysis-Social-Media-Engagement-Analytics-
Python for Data Analysis – Module End Assignment

####Assignemt title

Social Media Engagement Analytics

## 1. Introduction

This project is part of the Module-End Assignment for the Python for Data Analysis module. The objective is to analyse a social media engagement dataset using Python and understand the patterns and factors influencing user engagement.

## 2. Objectives

- Perform data loading and exploration.

- Clean and preprocess the dataset.

- Handle missing values and duplicate records.

- Perform feature engineering.

- Conduct Exploratory Data Analysis (EDA).

- Create visualisations using Matplotlib, Seaborn and Plotly.

- Identify meaningful insights from the analysis.

### 3. Dataset

The dataset used for this assignment is social_media_engagement_5000.csv, containing 5,000 records related to social media posts and user engagement.

It includes details such as age, gender, country, post type, post category, likes, comments, shares, impressions, watch time, device type and sentiment.

### 4. Technologies and Libraries Used

- Python

- Google Colab

- Pandas

- NumPy

- Matplotlib

- Seaborn

- Plotly

### 5. Tasks Performed

- Imported the required libraries and loaded the dataset.

- Explored the dataset using basic Pandas functions.

- Checked and handled missing values.

- Checked for duplicate records.

- Performed data cleaning and preprocessing.

- Created new features such as hashtag count, engagement score and log likes.

- Performed Exploratory Data Analysis.

- Created visualisations using Matplotlib and Seaborn.

- Created interactive visualisations using Plotly.

- Analysed the results and identified key insights.

##### 6. Conclusion

Through this assignment, I gained practical experience in using Python for data analysis. I learned how to clean and prepare data, perform exploratory analysis, create different types of visualisations and interpret the results to identify useful insights from a dataset.
